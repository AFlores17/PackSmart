# PackSmart
PackSmart is a camping and hiking backpack-planning web app that helps beginners enter backpack information, choose from a starter backpack list, and save backpack details using HTML, CSS, and JavaScript.

## Current Features

- Backpack information form
- Manual backpack entry
- Starter backpack CSV list
- Dropdown selection for backpack models
- Saved backpack information display
- Outdoors-inspired hunter green design

## Planned Features

- Trip details screen
- Packing list screen
- Item categories
- Weight tracking
- Trip history
- Save up to 15 trips locally
